# Data notes

- `experiment_dataset.csv` is the team's supplied ten-question dataset, copied from the experiment package. It contains reference answers and evidence annotations for the original comparison.
- `router_training.csv` contains only the ten question prompts and manually grouped workflow-role labels used for the separate router model. The grouping is documented in `MODEL_CARD.md`.
- Evaluation and run logs preserve the records described in the team's report. Scores are user-supplied and the report states independent second-rater scores were unavailable.
- Source-paper PDFs and raw model-output JSON files were omitted from this cleaned repository. Keep source citations and permissions with any materials shared elsewhere.
